# Website Belajar IPS Kelas 11

Proyek ini adalah website pembelajaran untuk mata pelajaran IPS (Ilmu Pengetahuan Sosial) Kelas 11, yang meliputi:
- Ekonomi
- Sejarah
- Geografi
- Sosiologi

## Fitur
Website ini terhubung langsung dengan **Google Spreadsheet** untuk menyimpan data siswa (absen, nilai, atau pesan) tanpa memerlukan database khusus, menggunakan Google Apps Script.

## Cara Menggunakan
1. Buka file `script.js`.
2. Ganti teks `URL_WEB_APP_GOOGLE_SCRIPT_KAMU_PASTE_DISINI` dengan URL hasil deploy (Terapkan) dari Google Apps Script kamu.
3. Upload semua file ini (termasuk folder jika ada) ke repository GitHub kamu.
4. Aktifkan **GitHub Pages** melalui menu *Settings* > *Pages* di repository GitHub kamu.
5. Website kamu sudah siap digunakan secara online!

## Struktur File
- `index.html` : Kerangka form dan tampilan utama.
- `style.css` : Desain agar tampilan website lebih menarik.
- `script.js` : Logika untuk mengirimkan data ke Google Spreadsheet.
- `README.md` : Penjelasan proyek (file ini).
